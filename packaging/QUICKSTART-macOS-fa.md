# ساخت نسخهٔ مک

این فایل را روی همان مکی باز کنید که می‌خواهید با آن بیلد بگیرید.

> Terminal را از `Applications › Utilities › Terminal` باز کنید،
> یا `Cmd + Space` بزنید و بنویسید `Terminal`.

---

## راه کوتاه — یک دستور

اگر فقط می‌خواهید کار راه بیفتد، این سه خط را یکی‌یکی کپی کنید و Enter بزنید:

```bash
cd ~/Desktop
git clone https://github.com/aminullah-dev/MediFlow.git
cd MediFlow && git checkout claude/vibrant-cerf-1wduo7 && bash packaging/setup-macos.sh
```

خط سوم بقیه‌اش را خودش انجام می‌دهد: ابزارها را چک می‌کند، پایتون را
(در صورت نبودن، با Homebrew) نصب می‌کند، کتابخانه‌ها را می‌گیرد، تست‌ها
را اجرا می‌کند، و بعد برنامه را می‌سازد. نیم‌ساعتی طول می‌کشد؛ بیشترش
دانلود است.

اگر چیزی کم باشد، **متوقف می‌شود و می‌گوید دقیقاً چه کار کنید** — مثلاً
«پایتون را از این آدرس نصب کن و دوباره اجرا کن».

در انتها یکی از این سه چیز را می‌گوید:

- **«Ready to ship»** → فایل `.dmg` ساخته شد، به کلینیک بدهید. تمام.
- **«this build cannot leave this Mac»** → گواهی اپل ندارید. **قدم ۷ و ۸**
  پایین این فایل را انجام دهید، بعد دوباره همان دستور را بزنید.
- **«The notarytool credential profile … does not exist»** → گواهی دارید
  (قدم ۷ انجام شده) ولی رمز مخصوص برنامه را ثبت نکرده‌اید. فقط **قدم ۸**
  مانده. خود اسکریپت دستور دقیقش را چاپ می‌کند.

قدم ۷ و ۸ تنها کارهایی هستند که هیچ اسکریپتی نمی‌تواند برایتان انجام دهد،
چون ورود به حساب اپل شما با تأیید روی گوشی خودتان را لازم دارند.

> **عجله دارید و فقط می‌خواهید روی فلش ببرید؟**
> `bash packaging/setup-macos.sh --no-notarize`
> نتیجه امضا شده ولی تأیید اپل ندارد: با فلش نصب می‌شود، ولی اگر دانلود
> شود مسدود می‌گردد. برای تحویل نهایی به کلینیک این را استفاده نکنید.

---

## راه بلند — قدم به قدم

اگر راه کوتاه خطا داد، یا می‌خواهید بدانید هر قدم چه می‌کند، از اینجا
بروید. هر قدم یک دستور دارد؛ کپی کنید، بچسبانید، Enter بزنید.

---

## قدم ۰ — ببینید این مک چیست

```bash
uname -m ; sw_vers -productVersion
```

خروجی دو خط است:

- خط اول `arm64` یعنی مک **Apple Silicon** (M1 به بعد)، `x86_64` یعنی **Intel**.
- خط دوم نسخهٔ macOS است.

این را یادداشت کنید. برنامه‌ای که می‌سازید فقط روی همین نوع مک اجرا می‌شود —
یعنی اگر کلینیک مک Intel دارد و شما روی Apple Silicon بیلد بگیرید، کار نمی‌کند.
شرحش در `packaging/README.md` بخش Architecture آمده.

---

## قدم ۱ — ابزارهای اپل را نصب کنید

```bash
xcode-select --install
```

یک پنجره باز می‌شود، روی **Install** بزنید و صبر کنید تمام شود.
اگر پیام داد «already installed»، یعنی از قبل هست؛ رد شوید.

---

## قدم ۲ — پایتون را نصب کنید

از [python.org/downloads](https://www.python.org/downloads/macos/) نسخهٔ
**3.13** را دانلود و نصب کنید (فایل `.pkg`، مثل هر برنامهٔ دیگری).

پایتونی که خود مک دارد کافی نیست.

بعد از نصب، بررسی کنید:

```bash
python3 --version
```

باید `Python 3.13.x` بنویسد.

---

## قدم ۳ — کد را بگیرید

```bash
cd ~/Desktop
git clone https://github.com/aminullah-dev/MediFlow.git
cd MediFlow
git checkout claude/vibrant-cerf-1wduo7
```

از این به بعد **همهٔ دستورها باید داخل همین پوشه اجرا شوند**.
اگر Terminal را بستید و دوباره باز کردید، اول این را بزنید:

```bash
cd ~/Desktop/MediFlow
```

---

## قدم ۴ — کتابخانه‌ها را نصب کنید

```bash
python3 -m venv .venv-mac
./.venv-mac/bin/pip install --upgrade pip
./.venv-mac/bin/pip install -e ".[dev]"
```

قدم آخر چند دقیقه طول می‌کشد (PySide6 حجیم است). صبر کنید.

---

## قدم ۵ — اول مطمئن شوید برنامه اجرا می‌شود

```bash
./.venv-mac/bin/python -m mediflow
```

پنجرهٔ ورود MediFlow باید باز شود.

بار اول یک کاربر `admin` ساخته می‌شود و رمز موقتش در این فایل نوشته می‌شود:

```
~/Library/Application Support/MediFlow/INITIAL_ADMIN_PASSWORD.txt
```

برای دیدنش:

```bash
cat ~/Library/Application\ Support/MediFlow/INITIAL_ADMIN_PASSWORD.txt
```

وارد شوید، رمز را عوض کنید، بعد آن فایل را پاک کنید.
برای بستن برنامه، پنجره را ببندید.

**اگر این قدم کار نکرد، جلوتر نروید.** مشکل در بسته‌بندی نیست، در نصب است.

---

## قدم ۶ — بیلد آزمایشی (بدون گواهی)

```bash
bash packaging/build-macos.sh
```

چند دقیقه طول می‌کشد. در انتها می‌نویسد:

```
==> App built: dist/MediFlow.app
  Architecture : arm64
  Requires     : macOS 13.0 or later
```

حالا در Finder به پوشهٔ `dist` بروید و روی `MediFlow.app` دابل‌کلیک کنید.
باید باز شود.

**این نسخه فقط روی همین مک کار می‌کند.** برای دادن به کلینیک نیست.
هدف این قدم فقط این است که ثابت شود بسته‌بندی سالم است، قبل از اینکه
سراغ گواهی بروید. اگر اینجا خطا خورد، خطا را بفرستید — مشکل از گواهی نیست.

---

## قدم ۷ — گواهی Developer ID بسازید

۱. به [developer.apple.com/account/resources/certificates](https://developer.apple.com/account/resources/certificates)
   بروید و با اپل‌آی‌دی خودتان وارد شوید.
۲. روی **+** بزنید.
۳. از فهرست **Developer ID Application** را انتخاب کنید — نه گزینه‌های دیگر.
۴. مراحل را تا آخر بروید و فایل گواهی را دانلود کنید.
۵. روی فایل دانلودشده دابل‌کلیک کنید تا در Keychain نصب شود.

حالا بررسی کنید نصب شده:

```bash
security find-identity -v -p codesigning | grep "Developer ID Application"
```

باید یک خط برگرداند که داخلش `(27RXPRW77S)` باشد.
اگر چیزی برنگرداند، گواهی نصب نشده — قدم ۷ را دوباره انجام دهید.

---

## قدم ۸ — رمز مخصوص برنامه بسازید

۱. به [account.apple.com](https://account.apple.com) بروید.
۲. بخش **Sign-In and Security** › **App-Specific Passwords**.
۳. یکی بسازید، اسمش را بگذارید `MediFlow`.
۴. رمزی که نشان می‌دهد (شکل `abcd-efgh-ijkl-mnop`) را کپی کنید.
   **این رمز فقط یک‌بار نشان داده می‌شود.**

حالا یک‌بار — و فقط یک‌بار — این را اجرا کنید. به‌جای دو مقدار داخل
گیومه، اپل‌آی‌دی خودتان و رمزی که ساختید را بگذارید:

```bash
xcrun notarytool store-credentials "MediFlow" \
  --apple-id "your-apple-id@example.com" \
  --team-id 27RXPRW77S \
  --password "abcd-efgh-ijkl-mnop"
```

این رمز در Keychain همین مک ذخیره می‌شود. **هرگز داخل پروژه ننویسیدش.**

---

## قدم ۹ — بیلد نهایی

همان دستور قدم ۶، بدون هیچ تغییری:

```bash
bash packaging/build-macos.sh
```

این بار چون گواهی نصب است، اسکریپت خودش پیدایش می‌کند، برنامه را امضا
می‌کند، برای اپل می‌فرستد تا تأیید شود (notarization)، و مهر تأیید را
داخل فایل می‌چسباند.

فرستادن به اپل **چند دقیقه طول می‌کشد** و اینترنت می‌خواهد. صبر کنید.

در انتها می‌نویسد:

```
Ready to ship: dist_installer/MediFlow-0.2.0-arm64.dmg
  Notarised and stapled — it opens on a clinic Mac with no internet.
```

**همین فایل `.dmg` چیزی است که به کلینیک می‌دهید.** روی فلش کپی کنید،
یا ایمیل کنید. گیرنده دابل‌کلیک می‌کند و MediFlow را به پوشهٔ
Applications می‌کشد. چون مهر تأیید داخلش چسبیده، روی مکی که هیچ‌وقت
اینترنت نداشته هم باز می‌شود.

---

## اگر خطا خوردید

خروجی کامل Terminal را کپی کنید و بفرستید. مخصوصاً:

- **قدم ۵ خطا داد** → مشکل نصب است، نه بسته‌بندی.
- **قدم ۶ خطا داد** → مشکل بسته‌بندی است. به گواهی ربط ندارد.
- **قدم ۹ در مرحلهٔ notarization رد شد** → دلیل دقیقش را اپل می‌گوید.
  شمارهٔ submission که در خروجی آمده را بگذارید اینجا و اجرا کنید:

  ```bash
  xcrun notarytool log <شمارهٔ-submission> --keychain-profile MediFlow
  ```

---

## قبل از هر تحویل، یک‌بار چک کنید

```bash
bash packaging/verify-macos.sh
```

سه نوع فایل ممکن است ساخته باشید و از روی اسمشان قابل تشخیص نیستند. این
دستور از خود سیستم‌عامل می‌پرسد، نه از چیزی که موقع بیلد چاپ شده بود، و
در انتها یکی از دو جمله را می‌گوید:

- **«Safe to hand to a clinic»** → روی فلش بریزید.
- **«Do NOT hand this to a clinic»** → دقیقاً می‌گوید چه چیزی ایراد دارد.

مهم‌ترین چیزی که چک می‌کند: `.dmg` را باز می‌کند و می‌بیند برنامهٔ **داخلش**
هم مهر تأیید دارد یا نه. یک `.dmg` مهرخورده که برنامهٔ بی‌مهر داخلش باشد
اینجا سالم به نظر می‌رسد و روی مک بدون اینترنت رد می‌شود.

## دفعهٔ بعد

قدم‌های ۱ تا ۸ فقط یک‌بار لازم‌اند. برای هر نسخهٔ بعدی فقط:

```bash
cd ~/Desktop/MediFlow
git pull
bash packaging/setup-macos.sh
```

اسکریپت می‌بیند که همه‌چیز از قبل نصب است، از رویشان رد می‌شود، و مستقیم
می‌رود سراغ بیلد.
